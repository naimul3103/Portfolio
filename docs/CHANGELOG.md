## Decisions worth remembering

| Decision                                 | Reason                                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------------------------------ |
| No client framework                      | every interaction fits in < 2 KB; a framework would be a cost with no user-visible benefit |
| Static stack pages instead of JS filters | filterable without shipping a runtime, and each stack page is a real URL                   |
| Stack pages only for ≥ 2 projects        | avoids thin duplicates of a single project page                                            |
| Content lives outside `src/`             | the database should not be inside the application                                          |
| Metrics required by schema               | the alternative is trusting a tired author at midnight                                     |
| Honest empty states                      | a gallery with stock photos is a lie with better art direction                             |
